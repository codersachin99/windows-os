# Source Desktop New submenu — React source migration

**Pinned original:** `codersachin99/legacy-win7@4e63290d783009e1293433c6ccf252abba9c1187`, `src/modules/system/main.js` background context menu: Folder, Shortcut, Rich Text Document, Text Document, in that order. Shortcut calls `OpenWindow("shortcut")` for the original dedicated `src/modules/shell/shortcutwiz.js` wizard.

**Shared VFS implementation:** `packages/ui/src/desktopCreate.ts` operates only on `sourceFilesystemRuntime.snapshot().desktopPath`. `VirtualFileStore.createFile` rejects any existing file, never silently overwrites. Folder, empty TXT and minimal syntactically valid RTF items are persisted and can be renamed directly. Shortcuts use exact source JSON `{exe,icon}` content in `.lnk` files and validated pinned program IDs; host commands/external paths are not executable here. Source `4cca` name suffixes ` (2)`, ` (3)` are used when a shortcut filename already exists, and invalid/reserved/control-character Windows names are rejected. Callers needing strict collisions can specify `{collision:"reject"}`.

**Native React UI:** desktop New → Shortcut now launches the shared window-managed `shortcut` app in a centered non-resizable 550×400 window, with a separate Browse dialog. The latter lists pinned installed programs (including unported programs visibly marked pending), supports row selection/double-click, OK/Cancel, and Finish only after a target and label are chosen. Source-listed but unported applications never launch arbitrary commands; their shortcuts are valid metadata for later implementation. The earlier HTML-select chooser was removed. Folder and file actions still offer inline rename. The original wizard's precise list ordering/iconography/localization and screenshot matching are ongoing parity work. WordPad/RTF editing remains pending.

**Verification:** `desktopCreate.test.ts`, `shortcutWizardModel.test.ts`, `desktop-create.spec.ts` and `shortcut-wizard.spec.ts` cover real filesystem creation, source shortcut serialization, duplicate suffixes, invalid inputs, Browse/Finish/Cancel and safe unported-app handling. Initial New submenu run [43197537081](https://github.com/codersachin99/windows-os/actions/runs/43197537081) passed. Dedicated wizard [43207440829](https://github.com/codersachin99/windows-os/actions/runs/43207440829) passed TypeScript, **127 unit and 122 Chromium browser tests**. Source Shortcut/File/Folder/Notepad/Calculator/Paint assets were subsequently restored byte-exact in [SHORTCUT-ICON-ASSETS.md](SHORTCUT-ICON-ASSETS.md).

**Still incomplete:** full legacy wizard theme/image/localization parity, all desktop app associations, native desktop-to-Explorer drag/drop, complete original menu layout, non-Guest accounts and remaining apps. `system/main.js` and `shell/shortcutwiz.js` remain in-progress; draft PR is not release-ready.
